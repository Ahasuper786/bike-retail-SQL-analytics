# Data

The source material contains seven CSV files:

- `brands.csv`
- `categories.csv`
- `customers.csv`
- `order_items.csv`
- `orders.csv`
- `products.csv`
- `stores.csv`

For a local rerun, place them under `data/raw/`.

The raw coursework files are intentionally not included in the public-ready repository because the original licensing/provenance was not established. In addition, the customer table contains contact-style fields, so only aggregate, non-identifying results are published.
